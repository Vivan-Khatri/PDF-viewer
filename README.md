[2] Advanced PDF Viewer

A lightweight PDF viewer built with Python and Tkinter. It allows users to open and view PDF files with basic navigation, zoom, scrolling, and light/dark mode support.

Features
  Open PDF files
  Previous / Next page navigation
  Zoom in / Zoom out
  Page number and zoom percentage display
  Scroll through PDF pages
  Light / Dark mode
  Simple and clean interface
  
Tech Stack
  Python
  Tkinter
  PyMuPDF
  Pillow
  
Project Structure
  PDF_Viewer/
  ├── main.py
  ├── pdf_viewer.py
  ├── theme.py
  └── requirements.txt
  
Installation
  Install the required libraries:
  
  pip install -r requirements.txt

Run the application:

python main.py

Purpose
  This project was created as a simple Python GUI project to practice file handling, PDF rendering, Tkinter widgets, and basic modular programming.
